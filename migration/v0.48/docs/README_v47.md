# FutureLab V0.47

V0.47 adds a multi-period periodic-review inventory policy experiment over the previously audited UCI Online Retail II recorded-sales panel. It simulates deterministic lead-time pipelines, base-stock and `(s,S)` policies, lost sales, holding costs and fixed order costs. It compares global and group-normalized cumulative lead-time residual calibration under frozen chronological train/calibration/selection/test partitions.

The new results are a simulated proxy only: the source data has no actual inventory or stockout records and the cost scenarios are assumptions. The V0.43–V0.45 Hillstrom marketing causal-evaluation protocol is unchanged.

See `V47_PROTOCOL.md`, `OPEN_SOURCE_REVIEW_V47.md` and the root `REPORT.md`.
