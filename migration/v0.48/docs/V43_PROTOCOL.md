# V0.43 protocol (specified before accessing real outcomes)
Primary data: Hillstrom, Men's email vs no email, randomized assignment conditional on the two arms; known design propensity 1/2. Secondary: Women's email vs no email (separate comparison, overlapping controls; not independent replication). Input mirror SHA256 bab6578f60db5d792f1c2372c502f029152a5249cf5ea84390f3b7f885d7234f, 64,000 rows. No real outcomes were loaded when writing this protocol. Use only pre-treatment fields; no exposure/visit/conversion as features. 60/20/20 stratified train/validation/holdout, seed 431901. Primary endpoint revenue spend × assumed margin 0.3 minus $0.05 per assigned email, cap 25% of customers, NOT measured profit. Costs .0/.05/.2 and caps .1/.25/.5, margins .1/.3/.5: secondary descriptive sensitivity, no retuning on test. Visit/conversion future secondary endpoints. Train all nuisance/score models only on train; choose strongest standard baseline and FutureLab conservative score parameter on validation at primary conditions, freeze and compare paired AIPW on held-out data using train-only T-XGB nuisance. IPW sensitivity. Approximate paired normal 95% CI, conditional on fitted policies and test cohort; no causal generalization or multiplicity guarantee for secondary comparisons. Success only if primary CI lower bound >0 and estimate >=10% of positive baseline incremental net value; if baseline <=0, relative lift undefined, require positive absolute lower bound and separately report estimate. No-touch allowed; budget cap not quota. Fixed random policy uses deterministic seeded priorities, no test outcomes. Baselines: random, recent purchase, past category rule, treated outcome XGB, linear interaction (ridge), T-XGB, cross-fit DR ExtraTrees (point score). Honest Causal Forest optional econml implementation, explicitly unavailable if not installed; no stand-in labeled causal forest. FutureLab candidate: cross-fit DR with bagged ExtraTrees, score mean minus lambda×ensemble dispersion (heuristic, not confidence bound), lambda in {0.5,1,2}; lambda selected on validation. This is a new static adapter corresponding to risk-aware learning, not V0.42 dynamic engine. Synthetic smoke not evidence of commercial value. Criteo and true dynamic validation excluded until raw data and time/assignment metadata are obtained. No data re-distribution. Holdout one-shot after user obtains data; do not use outputs for further tuning without a fresh independent holdout.
