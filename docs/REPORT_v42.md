# FutureLab V0.42 技术报告：自适应证据路由

## 1. 研究动机与范围
V0.41 的三来源投票只在至多一个来源失效且诚实来源跨批次 iid 正态、偏差已校正时具有风险保证。若两个来源使用同一故障机制，它们并不是两份独立的安全证据。V0.42 保留旧实现，新增以外部申报故障域为单位的路由器；在冻结候选与参考策略上评价，未修改因果档案训练，也未做审计样本再优化。全部数据为合成。

## 2. 方法和保证
令 L 为旧策略相对重算参考的净损失，epsilon=.035。每个源 s 的校正块 Y=X-N 对诚实域满足 iid Gaussian，均值 L+b_s，残余偏差绝对值 <= B_s。B_s 为独立实验设计论证所给出的外部上限，不由本数据拟合。没有有限上限的来源不参与认证。每个故障域预先选择成本最低的合格代表（并列按输入顺序），避免同域重复投票；并不等价于学习依赖图或证明真实独立性。跨域同期相关不影响下面的并集界，但跨批次相关会破坏单源 t 界。

预先固定每源查看时刻 k=3,6,9，m 为合格域数，q=.05/(3m)。每源上界 U_s=mean(Y_s)+t_(1-q,k-1)*sd(Y_s)/sqrt(k)+B_s。重复常数数据不提供认证。若最多 f 个域任意失效，则需要 f+1 个不同域各自至少一次 U_s<=epsilon 才接受。在 L>epsilon 时必有诚实域的某个已预定上界小于 L；对所有诚实域及其前缀取并集，单次冻结不安全策略的接受概率 <= .05。该论证允许根据已获得数据选择后续来源与提前停止，不要求不同来源独立，也不保证跨时期家族风险、被接受样本中错误比例或参考策略绝对安全。未知 f 或域数不足时拒绝认证，不支付采样成本。若实际存在超过 f 的故障域、偏差超过声明、选择后才改变候选、非 iid 块或无效随机化，保证不成立。

路由优先探索尚未访问的低成本域，再按当前均值及样本方差投影的最终查看上界（启发式，不是严格 EVSI）选择下一次采样，不再采集已通过认证的域。所有方法最大预算为 36 个样本等价单位/不同动作群体（每个成对 target/control 块计2单位）；实际费用按不同动作群体数和样本单位数计。实现支持不同来源成本，但主实验为等成本，并没有验证异质费用下最优性，也没有显式学习域间权重。round_robin 使用相同代表、风险界和预算，按阶段顺序采样。adaptive_f2 把外部 f 声明设为2，adaptive_bound 把外部残余偏差界固定为 .06；它们在全部场景固定使用这些声明，不按真值动态切换。unknown_decline 表示无法论证故障上限的情况，不是自动检测共同偏差的模型。界的正确性需要额外真实性证据，实验只检验指定假设下行为。

## 3. 实验协议
控制实验：8种压力 × 3个损失位置 delta=(L-epsilon)/SD（1e-8, -.75, -1.5）× 20000 独立尝试=480000 条；同场景同种子下各方法共享潜在观测，标称SD=.12。4个来源A0/A1/B/C来自3个域；shared_domain_fault 对A0/A1加目标专属负偏差-3SD；two_domain_fault 另对B施加同偏差；bounded_common 所有目标-0.06；hidden_common 所有目标-3SD；matched 目标与负对照共享-1.5SD；variance4 噪声SD翻倍；serial 使用AR(1) .8。固定三源V0.41分别取 A0/A1/B 或 A0/B/C。所有方法最大样本等价预算36；故障声明、查看时刻和方法参数固定后运行，未依据结果调参。受控率的名义95%精确二项式区间见boundary.csv，未做多重比较校正。

动态实验：8个市场/审计组合，各60条新种子轨迹（共480条），80期、12期预热。正常审计包含不规则复现、随机游走、均值回归；其余压力在均值回归环境下生成。复用V0.39冻结候选轨迹，审计不反馈到档案或参考模型，方法共享同一候选与潜在观测。仅原模型门通过且候选和参考不同的动作触发审计。单次损失为两策略模拟净效果差，评价真值只供模拟器；每块标称SD=sqrt(.45*g)/G，g为不同动作群体数。样本单元费用=.0015；报告决策遗憾、原探测费与审计费之和，不含未测量的实际运营复用节省。按独立轨迹进行1500次配对bootstrap，名义区间见paired.csv。总策略时期记录=480*68*9=293760。各期并非独立。

## 5. 验收、限制、下一阶段
87项测试通过（76项历史+11项新测试）。开发测试抓到阶段计数更新导致单轮多次读取、预算越界及零方差数值舍入，已修复并复测。新测试覆盖同域去重、未知声明拒绝、预算、提前停止、成本与偏差界。源依赖关系仍只接受外部声明，未实现自动因果图发现，未实现审计样本的新策略优化。保持 V0.41 历史文件与原始归档。下一步优先验证真实独立实验来源与可识别的偏差上界、跨批次相关稳健推断；同时做分离训练/验证的策略再优化与端到端经济价值对照。尚未上传 GitHub 或验证真实业务数据。
