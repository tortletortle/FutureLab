# FutureLab V0.25 --- UCI Online Retail II 真实数据验证报告

**执行日期：2026-11-18**\
**数据来源：用户上传的 `online+retail+ii.zip`，内部文件
`online_retail_II.xlsx`**\
**实验范围：真实交易数据上的需求预测与非线性价格特征发现；不是完整 RDF
在线变化检测或因果定价验证。**

## 1. 执行摘要

本轮完成了原始工作簿读取、数据清洗、周级商品序列构造、三折滚动时间验证，以及
Ridge、验证集调参 Ridge、HistGradientBoosting、XGBoost 与 FutureLab
Symbolic Shadow 的对照。

主要结论：

1.  数据接入和滚动评估流程已实际跑通，7项自动化测试通过。
2.  价格字段对需求预测有增量预测信息：在三折平均 RMSE 上，加入价格后
    Ridge 改善约 **6.26%**，XGBoost 改善约 **8.44%**。
3.  当前 FutureLab Symbolic Shadow 未优于调参
    Ridge、HistGradientBoosting 或 XGBoost。
4.  符号特征只在第一折选择了
    `price_cub`，后两折没有选择任何新项，说明当前候选生成与选择机制的跨时间稳定性不足。
5.  该数据没有促销处理标记，也不是随机定价实验，因此不能从本实验得出价格弹性因果结论。

**结论：本轮验证证明了真实数据管线可用，但没有证明当前符号模型发现算法具备竞争优势。**

### 2.3 缺失周处理

没有交易记录的商品周保留为缺失值，不直接填成零销量。原因是数据没有库存、上架状态或缺货信息，无法判断"无交易"究竟代表零需求、未上架还是缺货。

滞后特征按真实日历周构造。若上一周缺失，不会把更早的一条观测错误当成上一周。

这使评价目标成为：**商品存在正向交易且历史滞后完整的周上的条件需求预测**，不是完整库存需求预测。

## 3. 实验设计

### 3.1 三折滚动时间切分

  折   训练区间   验证区间   独立测试区间     测试行数
  ---- ---------- ---------- -------------- ----------
  1    前60%      60%--70%   70%--80%              768
  2    前70%      70%--80%   80%--90%              816
  3    前80%      80%--90%   90%--100%             879

每折最终模型使用训练集和验证集合并训练。测试集不参与特征选择或超参数选择。

所有模型都加入商品序列 one-hot 固定效应，以控制不同商品的基础销量差异。

### 3.2 对照模型

-   Persistence：上一观测周需求基准
-   Ridge：固定 alpha=5
-   Ridge Tuned：在验证集上从 alpha ∈ {0.1, 1, 5, 8, 20, 50} 中选择
-   HistGradientBoosting：非线性树模型
-   XGBoost：非线性树模型
-   FutureLab Symbolic
    Shadow：训练集生成候选基函数，验证集选择特征，最终测试集只做评价

FutureLab 本轮候选主要包括价格二次项、三次项和分位数 hinge 分段项。由于
UCI 数据没有促销字段，促销交互项没有可用观测信息。

## 4. 三折平均预测结果

指标为三折各自指标的算术平均，不是把所有测试行合并后的 pooled
metric。RMSE 使用 log(1+demand) 尺度；MAE 和 WAPE
使用反变换后的销量单位。

  模型                          RMSE（log）↓   MAE（销量单位）↓        WAPE↓
  --------------------------- -------------- ------------------ ------------
  Persistence                         1.1198             189.72       72.34%
  Ridge（alpha=5）                    0.8974             150.47       56.69%
  Ridge Tuned                         0.8633             145.99       54.88%
  FutureLab Symbolic Shadow           0.9147             152.28       57.43%
  HistGradientBoosting                0.8475             145.14       54.67%
  XGBoost                         **0.8394**         **144.68**   **54.50%**

### 4.1 结果解释

-   FutureLab Symbolic Shadow 的平均 RMSE 比固定 alpha=5 的 Ridge 高约
    **1.93%**。
-   比验证集调参 Ridge 高约 **5.95%**。
-   比 XGBoost 高约 **8.96%**。
-   比 HistGradientBoosting 高约 **7.92%**。

当前模型发现流程没有展示出稳定的预测优势。

### 4.2 符号项跨折稳定性

  折   被选中的符号项
  ---- ----------------
  1    `price_cub`
  2    无
  3    无

这意味着第一折发现的三次价格项没有在后续两个时间窗口重复出现。当前证据不支持把它称为稳定的市场机制。

## 5. 按商品序列进行的配对 Bootstrap

以商品序列为重采样单位，先计算每条序列跨折的平均 RMSE
差，再对92条序列进行5,000次 bootstrap。

差值定义为：

`FutureLab Symbolic Shadow RMSE - 对照模型 RMSE`

正值表示 FutureLab 误差更大。

  配对比较                      平均每序列RMSE差      95% Bootstrap区间   序列数
  --------------------------- ------------------ ---------------------- --------
  Symbolic − XGBoost                     +0.0853   \[+0.0454, +0.1310\]       92
  Symbolic − Ridge(alpha=5)              +0.0178   \[+0.0124, +0.0235\]       92

这是按商品序列聚类的探索性区间，不是完整的时间块
bootstrap，也不能替代跨数据集外部验证。

## 6. 价格特征消融实验

比较相同时间切分和模型配置下"包含价格"与"不包含价格"的预测结果。

  模型        含价格平均RMSE   不含价格平均RMSE   加入价格后的相对RMSE下降
  --------- ---------------- ------------------ --------------------------
  Ridge               0.8974             0.9573                      6.26%
  XGBoost             0.8394             0.9168                      8.44%

这说明成交价格对该任务具有增量预测价值。

**但这不是价格的因果效应。**
价格可能与需求、促销、商品组合、客户构成等因素同时变化。没有随机价格干预或可信的准实验设计，不能将预测关联解释为价格弹性或调价收益。

## 7. 当前验证边界

1.  UCI Online Retail II 是观察性交易数据，不是随机定价实验。
2.  没有促销分配字段，不能验证促销增量效果。
3.  没有库存、缺货、上架状态，缺失周不能可靠解释为零需求。
4.  只选取早期训练销量排名前100的商品序列，不能证明对长尾商品或新商品有效。
5.  商品 one-hot
    固定效应意味着本实验主要评估已知商品的时间外推，不是未见商品迁移。
6.  XGBoost 与 HistGradientBoosting
    使用固定配置，尚未进行大规模超参数搜索。
7.  数据没有人工标注的市场变化点，因此不能计算在线变化检测的
    Precision、Recall 或 F1。
8.  Symbolic Shadow 是 V0.25 的真实数据适配原型，不是完整 RDF V0.24
    在线检测、持续更新与因果决策系统。

## 8. 下一阶段 V0.26 研发建议

### A. 修复符号发现的泛化问题

-   联合选择基函数与正则化强度，而不是固定 alpha=8。
-   使用嵌套滚动验证控制特征选择偏差。
-   对候选项数量和模型复杂度增加惩罚。
-   记录特征在不同时间窗口、不同商品上的选择频率。
-   只有跨窗口稳定且独立测试改善的项才进入长期机制库。

### B. 建立商品异质性模型

-   采用分层模型或部分池化估计商品级价格响应。
-   区分商品基础需求与商品级价格斜率。
-   检查价格变化是否在商品内部有足够支持。
-   对极少价格变化的商品拒绝输出可靠弹性估计。

### C. 转向有实验设计的数据

下一主数据集建议使用 Dominick's
的随机促销实验类别。需要先对照官方数据手册确认实验处理组、控制组、商品和周索引的匹配关系，再做因果估计。

### D. 单独验证在线变化检测

UCI
数据缺少真实变化点标签。下一步应建立带已知注入时间的受控漂移实验，并在
Dominick's/M5 上做无标签探索性监控，不能混淆两类结果。
